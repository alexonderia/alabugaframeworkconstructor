# Перенос композиций и размещение блоков

Следующая итерация продолжает реестр шаблонов Constructor.

| Возможность | Реализация | Файлы |
| --- | --- | --- |
| Перенос локального каталога | JSON версии 1, проверка всех записей до записи, встроенные изображения через существующий переносимый проект | `composition-file.ts`, `composition-library.ts` |
| Независимые копии при импорте | Новые идентификаторы, одна транзакция IndexedDB для всей коллекции | `storage/compositions.ts` |
| Каталог | Кнопка переноса и обновление миниатюр после импорта | `catalog.ts` |
| Размещение одного блока | Выбор существующей секции или слайда, поиск свободного места с исходными размерами, удаление из резерва после размещения | `sections.ts`, `editor-inspector.ts` |
| Сохранность | EditorSession, Undo/Redo и существующая очередь сохранения | `tests/templates.test.ts`, `tests/composition-transfer.spec.ts` |
| Архитектура | Чистый парсер коллекции входит в проверяемые модули документа | `scripts/import-boundaries.mjs` |
| Руководство | Описаны перенос коллекций и индивидуальное размещение | `docs/ru/author.md`, `docs/en/author.md`, `docs/ru/data.md`, `docs/en/data.md`, `docs/template-iteration.ru.md` |

Пути модулей указаны относительно `apps/editor/src`.

Пользователь может перенести до 100 композиций файлом до 100 МБ. При повторном импорте появляются копии. Изображения HTTP(S) сохраняются как внешние ресурсы. При отсутствии свободного места блок остаётся в резерве. Его исходные размеры и содержимое сохраняются.

При сохранении композиции очищаются адреса текстовых ссылок и действия кнопок в копии каталога. Исходный проект сохраняет адреса и действия. В каталоге хранятся пустые строки. При создании экземпляра Framework получает поддерживаемый заполнитель `#`.

Проверены 42 модульных теста и 12 целевых браузерных сценариев в Chrome, Firefox и WebKit. Все прошли. В браузере проверены перенос изображения в новый контекст, повторный импорт, отклонение некорректного файла, размещение блока, Undo/Redo и перезагрузка проекта. Полный набор браузерных тестов этой итерации не запускался.

Прошли типизация, проверки границ модулей и циклов, UI и форматирования, production-сборка и проверка документации RU/EN. Веб-образ собирается из локального production-вывода с конфигурацией nginx проекта.
