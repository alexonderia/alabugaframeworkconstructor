# Управление блоками по двум осям

Новые документы используют сетку Figma: 24 колонки, строка 64 px и промежуток 8 px, поля 100/176/100/48 px на холсте 1920×1080. Геометрия хранится в целых ячейках. Старые проекты сохраняют свои параметры, включая прежнюю сетку 12/64/16.

У выделенного блока курсор на границах и углах показывает направление изменения размера. Видимые кнопки перемещения и размера удалены. Перетаскивание за содержимое перемещает выделенный блок, двойной щелчок по тексту включает редактирование. Противоположный край при изменении размера остаётся на месте. Поддерживаются настройка шагов по обеим осям, показ сетки и ограничение перемещения одной осью с Shift. Стрелки при фокусе на блоке перемещают его, Shift со стрелками меняет размер. «Настроить сетку раздела» открывает расширенные настройки текущего раздела. На узких экранах сайта работают адаптивные размеры и порядок.

Курсоры перемещения и четырёх направлений размера используют SVG с толщиной линий 1,75 и скруглениями, как у иконок действий редактора. Цвета берутся из публичных токенов Framework: синий контур со светлой обводкой для контраста на изображениях. Размер 32 px и активная точка в центре не зависят от масштаба холста. Курсор сохраняется до окончания жеста, включая выход за холст; отпускание кнопки, Escape и отмена указателя возвращают обычные курсоры. Для каждого SVG задан системный запасной курсор.

| Модули | Изменение |
| --- | --- |
| `block-geometry.ts` | Расчёт геометрии ручек и округления шага |
| `block-controls.ts` | Настройки привязки и видимости сетки |
| `canvas-cursors.ts` | SVG-курсоры из токенов Framework и сохранение курсора на время жеста |
| `widget-handles.ts` | Перетаскивание и клавиатура для каждого направления |
| `editor-canvas.ts`, `canvas-affordances.ts` | Прозрачные области границ, перетаскивание блока, фокус и доступность инструментов |
| `editor-inspector.ts`, `main.ts` | Переход из привязки к редактированию сетки |
| `styles/canvas/controls.css` | Геометрия ручек и показ сетки |
| `tests/block-geometry.test.ts`, `tests/block-geometry.spec.ts` | Границы, направления, обе оси, шаги, масштаб, отмена и сохранение |
| `tests/editor-layout.spec.ts`, `tests/controls-layout.spec.ts` | Проверки курсоров на границах и отдельной панели действий |
| `package.json`, `scripts/import-boundaries.mjs` | Подключение тестов и проверка направления зависимостей |
| `docs/ru/author.md`, `docs/en/author.md` | Инструкции по новым инструментам |

Пути модулей указаны относительно `apps/editor/src`.

Изменение положения или размера применяется одной операцией EditorSession. При пересечении или выходе за допустимые границы операция отклоняется с сохранением исходной геометрии. Высота потоковых секций зависит от содержимого, для них показываются линии колонок. Презентация сохраняет формат 16:9 и пределы Framework.

Браузерные сценарии проверяют направления и курсоры на границах, перетаскивание за текст, двойной щелчок для редактирования, масштаб, шаг привязки, отмену и возврат исходной геометрии. Проверки панели действий, адаптивного режима и первого жеста после редактирования в настройках сохраняются.
