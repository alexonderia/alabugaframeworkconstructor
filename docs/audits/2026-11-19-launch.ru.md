# Диагностика запуска и сервисов

19 ноября 2026 года. Этап A8 [аудита архитектуры и UX](2026-11-13-architecture-ux.ru.md).

`npm run diagnose` проверяет редактор, API, доступность Ollama из API, модель и обе системы документации. Код завершения по умолчанию подходит для запуска редактора отдельно. В контейнерной проверке CI используется `--require-api`. Для полной установки предусмотрены `--require-ai --require-docs`.

`npm run docker:build` указывает версию из `package.json` и Git SHA для пары web/API. Рабочая копия с изменениями получает суффикс `-dirty`. Такая метка указывает на базовый коммит и состояние рабочей копии при сборке. Действующая версия проверяется по HTTP и сверяется с OCI-метками. Разные ревизии web и API приводят к ненулевому коду диагностики, если обе версии установлены.

Нативный запуск сначала ищет уже работающий Constructor. При доступном API он возвращает адрес редактора. Если API ещё не запущен, используется заданный адрес Ollama. Порядок запуска без ИИ, с нативной Ollama и с контейнерной Ollama приведён в [руководстве по эксплуатации](../ru/operations.md).

Проверено на работающих контейнерах. Web, API и оба сайта документации доступны. Версия и ревизия в HTTP совпали с OCI-метками образов. При выключенной Ollama запуск диагностики с `--require-api --require-docs` завершился успешно, с `--require-ai` завершился кодом 1. Положительный сценарий готовности, этап загрузки, несовпадение закреплённой версии и отключение Ollama проверены с тестовым HTTP-сервисом. Запуск нативной Ollama для проверки реальной модели отклонён автоматической проверкой с сообщением `blocked by policy`.

Для локальной пересборки использован кэш установки того же набора зависимостей. Штатная сборка получила `ECONNRESET` при `npm ci`, после ограничения числа соединений реестр ответил `401`. Изолированный контекст восстановил прежний манифест для слоя установки из кэша и подставил текущий перед сборкой. Журналы и JSON проверки находятся в `artifacts/diagnostics-2026-11-19`.

Прошли 35 модульных тестов редактора, 49 тестов ИИ и API, 7 тестов инициализации и диагностики, 6 браузерных сценариев Chromium на Docker. Проверки типов, формата и ссылок в руководствах также прошли.

При повторной проверке удалось запустить нативную Ollama 0.35.0 обычной командой `ollama serve` на `127.0.0.1:11434`. Контейнерный API подтвердил готовность закреплённой модели `qwen3.5:2b`. Диагностика с `--require-ai --require-docs` вернула код 0. Пробный запрос на генерацию вернул HTTP 200 и ожидаемый JSON за 9,8 секунды.
