# Доработки после аудита: этапы 1–2

Дата: 13 ноября 2026 года. Основание — [аудит архитектуры и UX](2026-11-13-architecture-ux.ru.md).

Уточнение 17 ноября 2026 года: заголовок секции/слайда и заголовки её текстовых элементов теперь редактируются независимо. Настройки изменяют только заголовок секции; автоматическая подстановка текста элемента и удаление совпадающих заголовков отменены. Поля остаются однострочными. Описание ниже фиксирует промежуточную реализацию от 13 ноября, а не текущую семантику заголовков.

## Выполнено

- Поле «Заголовок слайда» изменяет существующий первый заголовок текстового блока композиции, сохраняя переносы строк. Если текстового заголовка нет, поле по-прежнему редактирует отдельный заголовок слайда.
- В проектах, где уже есть оба заголовка, отдельный показан как «Дополнительный заголовок слайда». Он редактируется независимо; тексты не удаляются и не объединяются автоматически.
- Некорректный JSON, пустое тело, `null`, массивы и недопустимая структура запроса генерации возвращают `400` с сообщением «Некорректный запрос» вместо общего `503`.
- В ИИ-черновике используются названия типов из Framework registry: например, «Свойства: Текст» вместо «Свойства: text».
- Обновлены README и руководства RU/EN: схемы документа 1–5, IndexedDB 3, переносимый файл версии 3, редактируемая JSON-копия и HTML-результат. Описаны запуск без ИИ, контейнерная/нативная Ollama и отдельный справочник Framework.
- Версия Framework и поддерживаемый минимум при сборке руководств берутся из `package.json`; соответствующие утверждения больше не содержат вручную записанное `1.2.0`.
- Изменения внесены в Changelog. Образы API/web пересобраны, контейнеры перезапущены и healthy. Модель сообщает `ready: true`.
