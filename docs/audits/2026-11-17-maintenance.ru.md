# Продолжение плана: форматирование и границы зависимостей

Дата: 17 ноября 2026 года. Продолжение [плана после аудита](2026-11-13-remediation.ru.md), пункты A2 и A3. Изменения внесены в текущий checkout без коммита и публикации.

## Выполнено

- Отформатированы 62 TypeScript/CSS-файла `apps/editor/src`, включая `main.ts`, `app.ts`, `design.ts`, `properties.ts` и `storage.ts`. Строковые шаблоны оставлены без встроенного форматирования. Логика, порядок CSS-правил и формат пользовательских документов сохранены.
- Prettier 3.10.1 закреплён в `package.json` и lock-файле. Добавлены `prettier.config.mjs`, `npm run format` и `npm run check:format`. CI проверяет формат редактора, сценариев проверки границ и их тестов.
- Проверка импортов сохраняет защиту публичных API Framework и добавляет публичные exports AI, матрицу направлений workspaces, запрет относительного обхода пакетных границ и Node.js-модулей в editor/ai.
- Модули документа `model`, `sections`, `section-name`, `document-content`, `property-patch` и `editor-save` отделены правилом импортов от UI и хранилища. Их явный список необходимо расширять при последующих выделениях.
- Граф относительных импортов исходников workspaces проверяется на циклы. Учитываются реэкспорты, типовые запросы `import()`, статические и буквальные динамические импорты, `require`.
- Пять новых проверок включены в `npm test`: разрешённые и запрещённые зависимости, обход публичных exports, сбор графа, циклы и реальный запуск команды на временном workspace с намеренно неправильными зависимостями.
- Обновлены архитектура и разработка RU/EN, правила участия и Changelog.

## Границы этапа

Правила импортов не являются анализом всех runtime-зависимостей: вычисляемые динамические пути не входят в граф. Отдельный линт использования глобальных DOM/IndexedDB API не добавлялся; здесь защищены направления импортов. Форматирование остальных workspaces не включено в эту механическую правку. Firefox, WebKit и живая генерация модели на этом этапе не запускались.

Следующий пункт плана — выделение состояния и жизненного цикла сессии из `mountEditor`, затем разделение хранилища с сохранением общих транзакций и упорядочение входа CSS. Галерея, панели, ИИ-сценарий и профилирование больших документов остаются последующими этапами; этот отчёт не отмечает их выполненными.
