# Разделение Framework и Constructor

Исходный SHA: b048bc2546a3e05131f4451a1115f7282b13523b; контрольный тег split-baseline. Текущий репозиторий остаётся основным для Constructor, с прежним remote и историей. Новый Framework расположен рядом, в ../alabuga-framework, remote https://github.com/alexonderia/alabuga-framework.git. Исходный репозиторий не архивируется.

Framework содержит один npm-пакет с готовыми ESM/IIFE/CSS, декларациями, шрифтами и материалами. Дизайн-токены разделены на три слоя; эффективные значения и переопределения доступности сохранены. Публичные подмодули и DOM-контракт описаны в Framework docs/public-contract.md.

Constructor сохраняет editor, AI, server, модельные конфигурации, коллекции проектов и хранилище. Framework sources, build:framework и библиотечный режим Vite удалены. Статика материалов копируется только из установленного пакета. Browser fixtures обращаются к опубликованному API. Собственные RU/EN-руководства доступны по прежним адресам /docs/.

Миграция IndexedDB не вводится. Схемы 1–3 нормализуются в 3; оболочки файлов 1–3 и legacy без версии читаются. Будущая версия и отсутствующие материалы отклоняются до записи. Доступ к данным сохраняется благодаря прежнему origin.

Подробная документация перенесена по содержанию: Constructor имеет 11 тем RU/EN, Framework — 9 и прежний интерактивный справочник. Исходные AI/workspace-протоколы и исторические измерения сохранены с явным статусом. Восстановлены старые переходы и справочная ссылка Figma. Проверка всех 302 исходных файлов, ресурсов и конфигураций описана в [отчёте сохранности](split-preservation.ru.md); машинная карта — split-file-audit.json.

Перед выделением повторно прошли 57 модульных тестов, сборка и 88 Chromium-сценариев. Node 24.19.0/npm 11.17.0 доступны и модульный контрольный прогон на них успешен. Старые кешированные Firefox/WebKit несовместимы с текущим Playwright; загрузка актуальных браузеров завершалась сетевым таймаутом. Это ограничение среды, а не успешная полная матрица. Актуальные результаты после разделения записываются отдельно в отчёт приёмки.

Внешние параметры: GitHub-авторизация с правом создать приватный alexonderia/alabuga-framework, HTTPS-домен реестра, SSH-сервер и секреты Actions/Dependabot. До их подключения локальная приёмка использует отдельный Verdaccio на 127.0.0.1:4873. Продуктовый origin и работающие пользовательские контейнеры при тестировании не меняются.
