# Author guide

## Projects and samples

The gallery separates websites and presentations. The “+” card creates a project; choosing a sample creates an independent copy. Previewing does not change the modification date. Search matches names. A card menu supports renaming, downloading and moving to trash; trash supports restoration and permanent deletion.

## Templates and individual elements

The document outline is on the left, canvas in the centre and contextual properties on the right. Select a section or slide, open «Изменить компоновку» and compare layouts using your content. Incompatible layouts are not applied. Content, actions and identifiers are preserved.

Edit text directly on the canvas. Select an element for content, appearance and behaviour settings: corporate type sizes, colours, spacing, alignment and grid position. Undo restores the previous state. Author overrides take precedence over composition defaults.

## Images and slides

Choose a library asset or upload PNG, JPEG, WebP or GIF up to 2 MB. To crop, select the fill mode and drag the image inside its frame. Mobile focus is configured separately. Contain mode keeps the whole image visible.

Slides use a 1600×900 source canvas and scale as a whole. Choose full-slide or side-quarter/side-third backgrounds. «Подобрать оформление» proposes a layout without shortening your text. If content overflows, edit it or split the slide manually; validation never deletes content automatically.

## Actions and motion

A button can open a link, navigate to a section or slide, or control a modal. Recheck action targets after deleting content. Editing reveals all content; motion plays in preview. «Далее» and «Назад» navigate presentation steps. Reduced motion and printing preserve access to content.

## AI drafts

Open «Создать с ИИ», choose a fragment or document, then supply a request and source facts. Limits are five website sections or six slides. Review the proposed outline and the completed draft. Some text is inserted verbatim from supplied facts; this is disclosed in the draft.

Drafts are isolated from projects. Edit them, retry a section, cancel or resume generation. Slides also support automatic fitting. Acknowledge the content review before applying. A fragment is inserted as one undoable operation; a complete document creates a new project.

## Before delivery

Wait for «Сохранено в браузере». Check websites on mobile and presentations in full screen. Download a portable project as a backup. HTML with embedded local assets works without the model; external HTTP(S) resources require a network. Use browser printing for PDF and verify that every slide occupies a separate page.

## Tablet and phone sizes

Choose a screen in «Вид холста», open block properties and expand «Размеры и положение». Set percentage width and minimum pixel height independently for tablet and phone. Content can grow beyond the minimum height. «Автоматический размер» resets only the current screen. These settings apply to flow website sections; desktop grid and slide geometry remain separate.

The resize handle supports pointer input and arrows: left/right adjust width by 5 percentage points (10 with Shift), up/down adjust minimum height by 16 px. The move handle changes reading order. Escape cancels an active drag; Undo restores an applied size. Simulated device widths stay stable when properties open; use canvas scrolling or «Вписать» when space is limited.

Keyboard and screen reader users can activate the named block settings, move and resize buttons. Closing properties returns focus to the invoking button.

## Slide header and page number

Open Slide settings ? Appearance to find Presentation header and Page numbering. Headers share the same insets and type size across slides; edit the text or hide it. Empty text restores ALABUGA / project title. Numbers support visibility, format (01, 1 or 1 / total), bottom alignment and custom text. Empty values use the automatic slide order, including after reordering. Changes affect the current slide, support undo, persist in the project and appear in HTML/PDF.

Page numbering also offers independent Background and Text color controls. Choose transparent or a brand background and a separate text color; select From theme to restore automatic text color. Solid backgrounds add a small inset around the number.
