# Архитектура

Constructor использует Framework 1.1.0; минимальная поддерживаемая версия также 1.1.0. Компоненты интерфейса инициализируются только в принадлежащих редактору контейнерах с cleanup перед заменой DOM. DatePicker использует enhanced-компонент; динамические Select явно оставлены нативными. Editable-холст не проходит общую инициализацию компонентов.

`document-surface.ts` создаёт iframe с публичными standalone CSS/JS Framework. Тот же runtime используется автономным HTML и общей проверкой качества; код renderer в Constructor не копируется. Изоляция предназначена для размеров и маршрутизации документа; iframe содержит доверенный runtime и прошедший валидацию AFDocument. Preflight проверяет реальные viewport сайта 1440/768/390 px и слайды 1600 px и блокирует экспорт при переполнении или недоступном изображении.

В IndexedDB 3 внутренний счётчик Project.version защищает атомарные записи от устаревшей вкладки. BroadcastChannel уведомляет интерфейс, но проверка версии выполняется в транзакции. История индексирована по проекту; повторяющиеся материалы читаются пакетом. Кэш материалов ограничен 16 МиБ приблизительного объёма строк UTF-16. Очередь сохранения оставляет активную запись и последний ожидающий snapshot. Очистка материалов проверяет ссылки проектов, корзины, истории и ИИ-черновика под одной транзакцией; счётчик версии и служебные подписи структуры не входят в AFDocument.

## Границы пакетов

| Пакет | Ответственность | Зависимости |
| --- | --- | --- |
| framework | Схема, runtime, композиции, оформление, экспорт | Zod; без редактора |
| ai | Контракты, команды, генерация и проверки содержания | Публичные API framework, Zod |
| editor | Витрина, холст, свойства, IndexedDB, интерфейс ИИ | framework, ai |
| ai-server | HTTP, ограничения, Ollama, инициализация модели | Node.js, конфигурация модели |
| docs | Руководства Constructor и примеры из установленного пакета | framework |

Framework находится в отдельном репозитории и публикует @alabuga/framework. Constructor 0.7.0 использует точную версию 1.1.0 и собственный lock-файл. Внутренние editor, ai и ai-server остаются приватными workspaces приложения. Изменение библиотеки выпускается отдельно; приложение принимает его собственным PR. Переходы между пакетами разрешены только через публичные exports. Конфигурация модели остаётся в Constructor.

## Документ и отображение

Версия схемы остаётся 3. В документе хранятся секции, элементы, позиции, фон, типографика, действия и анимации. Runtime одинаков для холста, предпросмотра и экспорта. Редактор добавляет управление поверх результата и хранит историю изменений в EditorModel. Импорт схемы не требует DOM или CSS; измерение слайда и отображение требуют браузера.

## Материалы и экспорт

IndexedDB хранит изображения отдельно от структуры документа; ссылки используют `asset:` и устойчивый идентификатор. Адаптер редактора разрешает их перед отображением и экспортом. Библиотечный экспорт также принимает асинхронный `resolveAsset(id)` и явные CSS/JS автономного runtime. Он не обращается к IndexedDB.

Обработка изображений находится в framework; хранилище не импортирует редакторский экспорт. Автономный runtime уже собран в установленном npm-пакете и читается через публичные standalone.css и standalone.js. Constructor не собирает библиотеку. CSS, шрифты и сценарий встраиваются в итоговый HTML.

## Генерация

Запрос → структура → заполнение смысловых мест → команды → изолированный черновик → проверки → применение. AIProvider отделяет транспорт от генерации. GenerationServices передаёт браузерный подбор оформления; сам пакет ai не импортирует UI редактора. Проверка геометрии передаётся callback-функцией.

ИИ-панель загружается динамически. Изменения черновика не заменяют текущий проект до применения. Схема проекта не содержит запросы, состояния генерации или служебные отчёты.

## Решения и ограничения

Нет серверной базы проектов, аккаунтов и синхронизации. Docker volume модели не является резервной копией проектов. Сервер ИИ обрабатывает один запрос одновременно. Изменение этих правил требует отдельного архитектурного решения и миграционных тестов, а не скрытого расширения текущего рефакторинга.

## Адаптер и независимые сайты

apps/editor/src/framework-adapter.ts объединяет renderer, подбор оформления, адрес встроенных материалов и DOM-опоры inline-редактирования. Библиотека не импортирует IndexedDB, AI или сервер. Совместимость DOM, CSS и API описана в Framework docs/public-contract.md; нарушение этого контракта требует major-версии библиотеки.

Интерактивный справочник Framework — отдельный статический сайт. Руководства Constructor и /api/ai/ остаются на origin приложения. VITE_FRAMEWORK_DOCS_URL задаёт переход к Framework, CONSTRUCTOR_URL в сборке его документации — обратные ссылки. Изменение репозитория не меняет origin или структуру пользовательской БД.
