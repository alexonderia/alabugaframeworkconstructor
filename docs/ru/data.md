# Данные и восстановление

## Где находятся проекты

IndexedDB `alabuga-workspace` хранит проекты, материалы, версии, настройки и краткие сведения для витрины. Хранилище принадлежит браузерному профилю и origin: схема, имя хоста и порт. `localhost` и `127.0.0.1`, порты 5173 и 4176 — разные места хранения. Контейнер не содержит эту базу.

Состояние «Сохранено» показывается после успешного завершения транзакции. Просмотр и миниатюры не обновляют дату проекта. При ошибке записи оставайтесь в редакторе, повторите сохранение или скачайте переносимый проект.

## Резервная копия

Скачивайте файл проекта через витрину или редактор. Он содержит документ и необходимые локальные материалы и пригоден для повторного редактирования. HTML — готовый результат, а не замена переносимому проекту. Внешние HTTP(S)-изображения остаются внешними; для независимости загрузите их в библиотеку до экспорта.

Перед сменой домена, порта, браузера, профиля или очисткой данных скачайте проекты. Откройте новый адрес и импортируйте файлы. Автоматического переноса между origin и синхронизации между устройствами нет.

## Версии и корзина

Сохраняется до 20 версий после паузы редактирования, при выходе и перед восстановлением или заменой. Версию можно создать вручную в меню проекта. При восстановлении текущая версия сохраняется. Корзина удерживает проект и историю; автоматической очистки нет. Окончательное удаление подтверждается отдельно и не удаляет общие материалы других проектов. Удалённый проект не появляется из автосохранения другой вкладки.

При конфликте двух вкладок устаревшая запись отклоняется целиком. Можно сохранить свои правки отдельным проектом или открыть сохранённую версию. Для очистки изображений используйте «Хранилище и материалы»: приложение показывает использование и повторно проверяет ссылки перед удалением.

## Совместимость

Формат документа остаётся версии 3. IndexedDB обновляется до версии 3 с индексом истории по проекту. Миграции баз 1–2 сохраняют документы, материалы и версии. Старое локальное сохранение переносится однократно. При блокировке обновления базы закройте другие вкладки и повторите открытие.

## Отмена и аварийное восстановление

Отмена относится к текущей редакторской сессии; история версий и переносимый файл решают задачи долговременного восстановления. Черновик ИИ сохраняется отдельно и восстанавливается после перезагрузки. Не очищайте данные браузера для устранения ошибки до создания резервных копий. Для диагностики передавайте минимальный воспроизводимый проект без лишних данных.

## Совместимость после разделения

Имя БД alabuga-workspace и object stores сохраняются; версия 3 добавляет индекс revisions.project. Legacy-ключ alabuga.builder.document.v1 сохраняется. Документы схем 1–3 нормализуются в 3; оболочки проектов 1–3 и без version поддерживаются. Будущие версии и отсутствующие материалы отклоняются до записи. Массовая перезапись проектов при первом запуске не выполняется. Маркеры установленных коллекций, ревизии, корзина, tombstones и AI-черновики сохраняются. Внутренняя версия записи проекта не меняет формат AFDocument.
