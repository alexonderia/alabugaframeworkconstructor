# Начало работы

Alabuga Constructor — локальный визуальный конструктор адаптивных сайтов и презентаций 16:9. Содержание собирается из фирменных композиций и редактируемых элементов. Аккаунты, облачная публикация и совместное редактирование документов не входят в версию 0.7.0.

## Требования

Для разработки: Node.js 24, npm 11, Git. Точные версии указаны в `.node-version` и `package.json`. Для контейнеров нужен Docker Compose v2. Для обычной работы редактора не нужны Python, Ollama или GPU. Готовые шрифты и фирменные материалы входят в установленный npm-пакет Framework; их исходной копии в Constructor нет.

## Редактор без ИИ

```sh
node scripts/configure-registry.mjs https://npm.acom-offer-desk.ru/
npm ci
npm run dev
```

Откройте `http://127.0.0.1:5173/builder/` или `/demo/`. Vite сообщает фактический адрес; при занятом порте укажите свободный явно. Проекты привязаны к адресу браузера, включая порт.

## Собранное приложение

```sh
npm run build
npm run ai:server
```

Откройте `http://127.0.0.1:4176/demo/`. API может обслуживать приложение без запущенной модели. Для локального Windows-показа с автоматическим запуском установленной Ollama используйте `npm run demo`. Первичная нативная установка: `npm run ai:setup`.

## Docker

```sh
docker compose -f compose.yaml -f compose.build.yaml up --build -d
docker compose -f compose.yaml -f compose.build.yaml --profile ai up --build -d
```

Первая команда запускает приложение без модели. Вторая дополнительно подготавливает Ollama и Qwen3.5-2B. Первый запуск требует интернета для образов и весов. Последующие запуски используют постоянный том. Подробности и требования GPU: [Эксплуатация](operations.md).

## Первый результат

На витрине нажмите «Создать сайт» или «Создать презентацию». Выберите образец, замените заголовок, откройте предпросмотр, скачайте переносимый проект и HTML. Проект редактируется повторно; HTML предназначен для показа. Пошаговое описание: [Руководство автора](author.md).

Фактическая точность текста ИИ проверяется автором. Техническая готовность черновика не является гарантией достоверности.

## Реестр и документация

Пакет `@alabuga/framework` версии **1.3.1** ставится из внешнего HTTPS-реестра:

```text
https://npm.acom-offer-desk.ru/
```

В тестовом контуре чтение открыто, логин не нужен. Публикация закрыта. В проекте добавьте в `.npmrc`:

```ini
@alabuga:registry=https://npm.acom-offer-desk.ru/
```

Затем установите зависимости:

```sh
npm install --save-exact @alabuga/framework@1.3.1
```

Нужны Node.js 24 и npm 11. Для production-контура используйте отдельный read token и не оставляйте реестр анонимным. Реестр нужен установке и сборке, готовому приложению он не нужен.

Ссылка «Документация» открывает [интерактивный справочник Framework]({{FRAMEWORK_DOCS_URL}}). Этот сайт развёртывается отдельно; адрес задаётся VITE_FRAMEWORK_DOCS_URL при сборке. Руководства самого Constructor находятся здесь: [ИИ](ai.md), [проекты и материалы](projects.md), [подбор оформления](slide-fit.md).
