# Качество и ограничения

## Уровни проверок

Модульные тесты проверяют схему, команды, сохранность черновика, ошибки API и инициализацию. Браузерная регрессия проверяет интерфейс, сохранение, восстановление, доступность, изображения, эффекты, экспорт и адаптивность в Chromium, Firefox и WebKit. Отдельные нагрузочные сценарии используют 100 проектов и 50 слайдов с 500 элементами.

Сервер тестов использует выделенный порт 4275 и управляется Playwright. Он не переиспользует рабочий Vite автора на 5173 или приложение на 4176. При занятости порта тест должен завершиться понятной ошибкой, а не подключиться к неизвестному приложению.

## Реальная модель

```sh
npm run demo
npm run demo:rehearse
```

Репетиция использует отдельный браузерный профиль: проверяет модель, генерирует секцию и слайд, изменяет текст, применяет результат, повторно открывает и экспортирует без сети. Результаты сохраняются в artifacts; их не нужно коммитить. Браузерные тесты с имитацией API не заменяют этот прогон.

Для собранного нативного приложения `npm run test:model` запускает отдельный API на порту 4386 и завершает его после проверки. Для Docker перед этой командой задайте `AF_CHECK_URL=http://127.0.0.1:4176` (PowerShell: `$env:AF_CHECK_URL='http://127.0.0.1:4176'`). Контейнерный API продолжит работать. При доступном nvidia-smi сценарий измеряет память каждые 250 мс и сохраняет gpu-summary.json; сопоставляйте физический расход с данными о размещении слоёв Ollama. На ноутбуке с ограниченной RAM не запускайте одновременно браузерную регрессию, распаковку Docker-образов и генерацию.

Последний дорефакторинговый набор свободной генерации: 12 из 20 результатов пригодны по содержанию при 20 технически корректных. Это историческое измерение, а не гарантия текущей сборки. Полный новый прогон нужно оценивать отдельно по релевантности, полноте, фактам и оформлению. Улучшение геометрии не исправляет смысловые ошибки.

## Подготовка показа

Проверьте версию и digest модели, наличие материалов и полный GPU offload. Выполните «Проверить сценарий показа», прочитайте оба результата. Подготовьте исходные факты и готовые образцы, обозначенные как образцы. Во время выступления покажите шаблон, поэлементную настройку, реальную генерацию, проверку черновика и экспорт. Не выдавайте сохранённый пример за новую генерацию.

## Выпуск и известные границы

Приёмка рефакторинга 7 октября 2026: 264 браузерные проверки, ещё три проверки справочника и 57 модульных проверок прошли. Чистая копия собрала и экспортировала сайт из 10 секций и презентацию из 11 слайдов; Chromium создал PDF на 11 страницах. На RTX 3050 Ti 4 ГБ измеренный максимум в нативном Vulkan — 2967 MiB, в Docker/WSL2 — 3059 MiB; в обоих случаях полное размещение на GPU и контекст 4096. После прогрева Docker создал секцию за 5,079 с, слайд за 5,562 с; первый холодный запрос с загрузкой занял 66,56 с. Это два подготовленных сценария, а не новый тест качества содержания на 20 запросах. Полные отчёты и исходные измерения хранятся отдельно от исходников.

Перед выпуском требуется чистая установка, полная регрессия, автономный HTML и PDF из 11 страниц, визуальная проверка и явный список непройденных проверок. GPU, первая загрузка весов и контейнерная память отмечаются отдельно, если среда их не позволила проверить.

Исследование с пятью авторами и репетиция ведущего не заменяются автоматикой. Роли, совместная работа, серверные формы, поиск в интернете, генерация изображений и произвольный код автора не входят в текущую версию. Ошибки регистрируйте с версией, средой, шагами, ожидаемым и фактическим результатом.

## Проверки разделения

Приведённые выше замеры от 7 октября относятся к прежнему монорепозиторию и не заменяют текущую приёмку. Для разделения зафиксированы 62 модульных и 90 браузерных проверок Chromium через установленный Chrome, чистые потребители npm-архива, Docker smoke и локальное восстановление Verdaccio. Полная матрица Firefox/WebKit, реальная GPU-модель и production-инфраструктура пока не подтверждены. [ИИ](ai.md) и [проекты](projects.md) содержат исходные протоколы с явным статусом исторических измерений.
