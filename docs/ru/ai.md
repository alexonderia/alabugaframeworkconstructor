# Локальный ИИ

Подробное руководство перенесено из прежнего раздела справочника. Измерения от 2 октября 2026 года ниже являются историческими: новая GPU-приёмка после разделения ещё не выполнена.

## Локальный помощник

Qwen3.5-2B создаёт редактируемые секции и слайды из фирменных композиций. Сначала появляется отдельный черновик. Проект меняется только после команды «Применить черновик».

### Состояние прототипа — 2 октября 2026

Локальная генерация, редактирование черновика, восстановление, применение и отмена работают. Приёмка по качеству содержания пока не пройдена: 16 из 20 запросов прошли технические проверки, 12 из 20 признаны пригодными черновиками при проверке содержания агентом. Цель — 18 из 20. Модель иногда пропускает заданные пункты, повторяет фразы или оставляет образцовый текст. Служебные фразы блокируют применение до исправления; все факты требуют проверки автором.

На RTX 3050 Ti Laptop модель размещается полностью на GPU: контекст 4096, пик общей занятой видеопамяти 2967 МиБ из 4096. В последнем прогоне отдельные секции заняли 3–9 секунд, черновик из пяти секций — 30,6 секунды, из шести слайдов — 35,3 секунды; оба больших черновика потребовали ручных исправлений. Подробные результаты, исходные ответы и редакторская оценка: artifacts/ai/report.html. Демонстрационные HTML и PDF в этой папке прошли отдельную редакторскую правку; она не засчитывается в оценку модели.

### Установка и запуск

```sh
npm run ai:setup
npm run ai
```

Для установки нужны Windows x64, Python 3, Node.js 24.19.0 и npm 11.17.0 и доступ в интернет. Скрипт устанавливает официальный Ollama 0.35.0 в .local/ollama с компактным Vulkan-бэкендом и загружает qwen3.5:2b в .local/models. Исходный архив берётся из официального GitHub Ollama; извлекаемые файлы проверяются по размеру и CRC, их SHA-256 сохраняются в installation.json. Существующая Ollama на localhost:11434 может использоваться вместо встроенной.

Редактор открывается по адресу [127.0.0.1:4176/builder/index.html](/builder/). После загрузки модели интернет не нужен. Для разработки запустите npm run ai:server и npm run dev. Запросы /api/ai проксируются к локальному сервису.

### Как создать документ

- Нажмите «Создать с ИИ», выберите секцию, слайд, страницу до пяти секций или презентацию до шести слайдов.
- Опишите тему и аудиторию. Вставьте проверенные факты, контакты и ссылки в исходные сведения.
- При необходимости выберите до шести изображений. Для своих изображений заполните описание: модель получает текст, а не анализирует пиксели.
- Создайте черновик. Проверьте содержание и замечания. Текст можно изменить на холсте; свойства компонентов открываются кнопками под ним.
- Повторите выбранную секцию при необходимости. «Продолжить» сохраняет готовые части и использует прежнее задание; «Создать черновик» начинает новое задание с текущими полями.
- Проверьте черновик, подтвердите содержание и примените результат.

### Пример запроса

Создай презентацию из шести слайдов для авторов контента: зачем нужен визуальный конструктор, единый фирменный стиль, готовые композиции, редактирование, предпросмотр и экспорт.

Исходные сведения: Alabuga Constructor работает локально в браузере. Проекты сохраняются в IndexedDB. Есть готовые композиции, редактируемые тексты и изображения, HTML-экспорт. Презентации используют формат 16:9.

### Память и скорость

Целевое устройство — RTX 3050 Ti Laptop с 4 ГБ видеопамяти. Начальный контекст 4096 токенов, один запрос одновременно, рассуждение выключено. Используется явная загрузка всех слоёв на GPU (num_gpu=99): автоматический режим Ollama резервирует память для обработки изображений и на этом устройстве переносит часть модели в RAM. Размер файла модели не равен расходу видеопамяти. Проверенная сборка закреплена в config/model-lock.json; фактическая версия, digest модели и размещение в памяти записываются после запросов в artifacts/ai/runtime.json. Проверить окружение можно через /api/ai/diagnostics.

```sh
# PowerShell: повторная проверка с меньшим контекстом
$env:AF_AI_CONTEXT='2048'
npm run ai
```

Перенос части модели в RAM не считается подтверждением работы целиком в 4 ГБ видеопамяти. Если оба профиля не подходят, это фиксируется как ограничение устройства; другая модель автоматически не подключается.

### Команды и интеграция

AIProvider изолирует локальную модель от редактора. GenerationRequest задаёт режим, запрос, аудиторию и факты. GenerationProgress описывает этап и прогресс. DraftResult хранит структуру, секции и замечания. AICommand допускает createSection, setText, setCards, setMetric, setImage, setGallery, setQuote, setButton и setTable. Цвет и движение задаются фирменными вариантами команды создания; идентификаторы и сетку создаёт приложение.

Ответ ограничен JSON Schema, затем проверяется исполнителем команд и общей схемой документа. Модель не выполняет код. Документы остаются в схеме 3, служебные данные ИИ хранятся отдельно в IndexedDB. HTML не содержит зависимости от Ollama.

### Ошибки и восстановление

- Ollama недоступна или модель отсутствует: выполните npm run ai:setup.
- Превышен бюджет контекста: сократите исходные сведения и число выбранных материалов. Содержание незаметно не обрезается.
- Таймаут: запрос прекращается через 120 секунд. Готовые секции остаются в черновике.
- Переполнение или неверная команда: одна автоматическая попытка исправления на секцию; затем ручное редактирование или повтор.
- Место вставки удалено или изменён проект: откройте помощника из нужной секции и выберите «Вставлять после текущей секции».
- Сохранение не удалось: сообщение «Сохранено» не показывается, применение блокируется до успешной записи.

### Проверки

```sh
npm run test:ai
npx playwright test tests/ai.spec.ts
# Оставьте npm run ai или npm run ai:server запущенным
npm run ai:acceptance
```

Модульные и браузерные проверки используют явно обозначенные тестовые ответы. Отдельный сценарий ai:acceptance вызывает настоящую Qwen3.5-2B для 20 русскоязычных заданий и сохраняет результаты в artifacts/ai. Эти два вида проверки не заменяют друг друга. Проверяйте факты и качество русского языка перед публикацией.
