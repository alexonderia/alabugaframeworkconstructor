# Итерация шаблонов Constructor

Аудит выполнен на HEAD ветки `extract_framework` (`6128248`) с Framework 1.3.1.

| Требование | Текущее решение | Недостаток | Изменение | Модули |
| --- | --- | --- | --- | --- |
| Шаблоны сайта и презентации | Framework публикует каталог композиций, демонстрационные документы и эталоны. Старые фабрики секций используются в тестах | Выбор проекта и вставка секции обходят друг друга, версий нет | Реестр с версиями и типами ссылок на публичные фабрики | `templates`, `app`, `catalog`, `sections` |
| Смена композиции | Framework умеет переставлять элементы при полном совпадении мест | Несовпадение блокирует переход целиком, целевая сетка может отличаться | Смысловые роли, перенос совместимых блоков, подтверждение и отложенные блоки | `sections`, `variants`, `design` |
| Сайт и слайды | Runtime уже поддерживает адаптивный поток и геометрию 16:9. Поиск места смешивает правила | Границы компоновки проверяются на разных уровнях | Раздельные правила добавления и варианты с проверкой Framework | `layout`, `model`, `layout-chooser` |
| Интерфейс и токены | Есть структура, холст, инспектор, библиотека, inline-редактирование и масштабирование | Точные параметры видны наряду с основными; каталог показывает разные сущности через независимые входы | Единый каталог, режимы инспектора и корпоративные пресеты | `catalog`, `editor-inspector`, `editor-canvas`, `properties`, `design` |
| Сохранение и перенос | EditorSession, история, порционная очередь, IndexedDB и переносимый JSON | Строгий AFDocument не принимает произвольные метаданные | Проверяемое расширение Constructor, проекция для Framework, обработка всех материалов общей очередью | `document-validation`, `template-metadata`, `storage`, `project-file` |
| Просмотр, экспорт и ИИ | Standalone-рендерер Framework, preflight, изолированный ИИ-черновик | Экспорт HTML привязан к вызову из UI, ИИ принимает чистый AFDocument | Контракт экспортёра, работа с чистым документом на публичных границах | `editor-export`, `document-content`, `framework-adapter`, `main` |
| Проверки | Проверки границ и CSS, модульные и Playwright-тесты | Нет сценария новой системы целиком | Тесты реестра, переноса содержимого, режимов и полного пользовательского сценария | `tests`, `scripts/import-boundaries.mjs` |

## Границы текущей реализации

- Локальный каталог «Мои композиции» принадлежит браузеру. Во второй итерации добавлен перенос коллекций через JSON со встроенными изображениями.
- При сохранении композиции в каталог адреса текстовых ссылок и действия кнопок очищаются в копии. Ссылки исходного проекта сохраняются.
- Для отложенных блоков доступны размещение группы в новом разделе и перенос отдельного блока в существующий раздел с автоматическим поиском места.
- Формат презентации и ограничения геометрии задаёт Framework 1.3.1. Новый экспортёр может реализовать `DocumentExporter`.
