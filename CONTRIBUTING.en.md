# Contributing

[Русский](CONTRIBUTING.md)

1. Use one branch per task. Do not combine document-format changes with mechanical relocation.
2. Consume public package exports. Declare dependencies in the consuming package and update the shared lockfile.
3. Preserve routes, identifiers, actions, undo and user data. A failed write must never display “Saved”.
4. Run units, types, boundary checks and builds. Renderer, schema and persistence changes require full browser regression.
5. Update corresponding RU/EN pages. Add a usage example and negative case for new public APIs.
6. Describe the problem, resulting behaviour, compatibility and evidence limits in the PR. Do not describe mocked generation as real inference.

## Before the first push

Choose the private organization and repository name, enable Git LFS, required review and Quality checks. Protect main from direct pushes and assign actual teams in CODEOWNERS. Inspect staged files for secrets and large artifacts. No npm package publication is needed.

## Trusted GPU runner

The manual workflow runs only from main on a runner labelled `alabuga-gpu`. Configure the protected `gpu-acceptance` environment with team approval. The machine needs Ollama, the pinned model and a GPU. Never execute unreviewed PRs on this self-hosted runner. Acceptance starts its own API on port 4386 and terminates only that process.

## Source materials

Do not change original PPTX/Figma files during refactoring. Derived assets are regenerated by separate scripts and visually reviewed. Extraction requires Python, Pillow and fontTools; ordinary developers use prepared resources. Do not attach an open-source license to corporate materials without a separate owner decision.

## After the split

Configure the scoped registry and a read token for npm ci. Framework updates use separate exact-version/lockfile PRs, never copied library sources. Full protocols are in docs/en/{development,ai,projects,quality,operations}.md. Optional Python reports use scripts/requirements-reports.txt; original fonts, PPTX/Figma and asset generators belong to Framework. Keep the browser origin unchanged during release to preserve IndexedDB access.
